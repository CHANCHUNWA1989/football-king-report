## 已實作的自動運作

1. 原始 V4.1 ZIP 固定 SHA-256，與 `ops/` 額外防護分開保存，避免靜默改動原始程式。
2. 每日按香港時間 **03:17、09:17、15:17、21:17** 建立六個聯賽的公開賽程及中文網站（GitHub 雲端排程可能延遲）。
3. 六個公開賽程來源覆蓋英超、英冠、德甲、西甲、意甲、法甲；當次成功下載不等於獨立核實。
4. 網站在瀏覽器運行時超過 **10 小時**未更新，顯示 HOLD。獨立健康監控亦用相同十小時門檻，約每六小時檢查。
5. **品質檢查和強制網站安全提示：** 需要品質 JSON、模型驗證 JSON、獨立來源核對 JSON 及影子概率 JSON；缺漏就阻止部署。衝突／嚴重過期即 HOLD。
6. **德甲雙來源比對：** 額外由 OpenLigaDB 與 OpenFootball 對比可識別的同一賽事及已提供賽果；比賽不配對不代表一致；其他五個聯賽尚未雙來源核實。
7. **賽前影子概率：** 使用同一賽季、研究時間之前已結束的比賽訓練簡單收縮 Poisson 模型，僅對有明確開賽時間、距開賽至少 10 分鐘的候選產生主／和／客概率。**未校準、無賠率、不提供 EV 或投注建議**。
8. 每次運行存檔賽程時間點與影子概率觀測，以 `.json.gz` 壓縮保存於 `history/` 及 `shadow/`，按 GitHub 執行編號命名；不能宣稱 GitHub Git 歷史不可被帳戶管理者改寫。
9. 歷史市場概率檢定支持按時間的 1X2 Log Loss、Brier 及週區塊抽樣；沒有真實封存的賽前賠率和結果時，輸出 `HOLD, n=0`。
10. 網站發布與歷史存檔分離 GitHub 權限，前者無內容寫入權限；失敗時嘗試建立 GitHub 問題紀錄。問題紀錄不等於已確認送達 iPhone。

## 真正尚未解決的限制

- 多家公司**實時及歷史**報價需要合法授權與可追溯資料；目前無自動接入。無法證明市場優勢、ROI 或 CLV。
- xG、傷停、正選等缺穩定合法、有時間戳的來源。
- 多數公開賽程只含比賽**日期**。2026-10-09 當次 207 場窗口賽事只有 27 場有明確開賽時間。
- 部分來源沒有可核實的上游更新時間；抓取時間不是上游發布時間。
- 德甲部分賽果經兩個獨立發布者比對；**唔代表其他五個聯賽、準確開賽時間或未來賽事全部核實**。
- Shadow Mode 已能自動儲存**未校準候選概率**，但目前沒有足夠真實的已結算樣本、賽前市場基準及前瞻表現證據。市場驗證仍 HOLD。
- 目前不具每場比賽精準 T-180／60／20／10 分鐘觸發保障；GitHub 例行排程有延遲且沒有賽前授權即時資料來源。
- 沒有 V2.8 原始碼，無法保證百分百兼容。
- GitHub 故障時工作流程和 GitHub 問題警報都可能失效；要保證手機通知送達，需獨立通知渠道及用戶設定。
- GitHub 儲存庫為公開，請勿加入 API 秘鑰、帳號密碼、客戶資訊或沒有再分發權利的資料。
