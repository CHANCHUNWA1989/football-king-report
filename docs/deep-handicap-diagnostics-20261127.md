# 深盤診斷引擎 DHE v1 — 2026-11-27

Research challenger only. 不改任何 A/B/C 原始預測、歷史封存、網站、正式推薦或 API 額度。

**缺口**：既有 `ops/asian_handicap_research.py` 已正確支援四分一盤；缺少獨立的深盤淨勝球診斷、贏波仍輸部分本金的機率及假設戰術減速壓力區間。新模組重用既有 grader，不從 1X2 反推分布。

- 主客雙向支援讓 1.5 至 5 球；五類亞洲盤結算、淨勝球五個桶。
- 27 個合成情境：主客入球率各 ±15%，半場領先至少兩球後下半場讓球方入球率乘 0.65/0.85/1。這些只是先驗敏感度設定，不是實測戰術效果或信賴區間。
- 基準與既有 Poisson 結算一致；壓力參數超出既有有效範圍時不輸出不完整區間。
- 無可成交賠率、EV 驗證、建議注碼或投注放行；所有輸出 HOLD / DISABLED。
- 無真實前瞻回測或資料源新增。後續須先封存同場同截止時間的完整比分分布、獨立盤口與賽果證據，按讓球線、主客、聯賽及領先情境分層比較；避免事後補錄與樣本重複。未有合格證據不可宣稱預測提升。

驗收：`python -m compileall -q ops`、`python -m unittest discover -s ops/tests -q`，另核對 DHE 專項 CI。測試只驗證數學及防越權，不代表預測有效。
