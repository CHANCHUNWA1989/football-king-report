# 第十八階段：私有輸入原件重構核對
第十七階段10項CI已成功；兩個PR查詢結果均無獨立審查／thread，七項證據閘門最新分支紀錄2026-11-26 UTC只有1 PASS、2 PARTIAL、4 HOLD。既有橋接只比對聲稱候選摘要與結構，重算摘要且保持合法概率質量可通過。新增合成回歸重現此缺口，並提供獨立較嚴格的私有重播入口。

要求影子預測、私有報價報告及候選報告三份既有JSON bytes及各自SHA256 pin；有大小限制及重複JSON鍵／非有限值防護。使用原先聲稱擷取時刻重執行 capture 的現行固定公式及來源閘門，對整個候選報告的canonical digest一致性檢查（含型別與額外欄位），其後才可選擇呼叫現有賽後bridge。合成測試涵蓋合法概率篡改且重新摘要、byte變更、重複鍵、非法數值、時間錯配、結果矛盾及型別變更；跨分支測試比較重構列與原合成列評估結果。沒有原始來源 HTTP response、獨立時間見證、簽名或公證，三份JSON是衍生輸入；呼叫者可同時偽造輸入及pins，故不證明原始真實性。舊版結構入口仍保留，本輪沒有改成強制接入、沒有真實私有檔案存取或排程，也沒有重算/覆寫封存。必須使用相容公式及運行版本，差異拒絕；無容差放行。所有輸出維持 HOLD/DISABLED，前瞻資格0；新CI待驗收。
