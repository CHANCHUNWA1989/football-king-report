# 第十六階段：五類結算分層校準診斷
重用既有配對評估器已驗證的結構輸入，新增 stratified_grade_calibration，原有輸出欄位不改。按資料類型、聯賽、精確讓球線及 baseline/challenger 版本組分離；每組至少100場及8個UTC ISO週才提供描述統計，並非統計效力或正式資格閘門。每個可行結算類別輸出平均預測、實際比例、帶符號差距及二元Brier；不可行類別獨立標記，不以大量結構零沖淡誤差。最高概率類別使用固定順序解決平手，計算平均信心與實際命中差。固定十箱，每箱至少20場才列出比例；若任何非空箱樣本不足，全組ECE為null，避免選擇性覆蓋。報告覆蓋比例。不將描述差距當成因果或正式過度自信證明；不擬合校準器、不更改原預測。既有 pooled 指標仍可作描述，版本混合不可作可靠校準。合成及未認證外部數據仍完全隔離，真前瞻為0。四組合成測試；新CI待驗收。第710跨分支測試仍固定之前已驗收的第711版本，更新固定版本需另行審核。HOLD/DISABLED。
