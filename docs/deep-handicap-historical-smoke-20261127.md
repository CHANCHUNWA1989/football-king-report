# 第九階段：真實歷史文件相容性測試

重用第八階段原有結構解析規則，將射門事件結構檢查與聲稱賽事時間證據檢查分離。新實檔測試不製造實際完場時間、擷取歷史或來源見證；不將現時可下載的歷史原件冒充過去模型已使用的數據。

固定來源 StatsBomb Open Data，https://github.com/hudl/open-data/tree/4b73468fc5b0f1950f9f66fada70ad3a4f9327cb 。實際核對2022世界盃索引的三個小組賽原生ID。只下載限定索引及三個事件文件，每檔上限20MB，HTTPS固定路徑，無密鑰、無重試風暴、無原件落盤或公開球員/隊伍xG。CI只列相容性結果、原件SHA256及總數，不上傳原始資料或研究數值。來源 README 規定發布研究時標示 StatsBomb 並使用標誌；此輪不發布分析或研究發現，全面研究分發前仍需審查完整使用協議。

任何下載、解析失敗會使專項CI失敗。通過只意味實檔結構相容，不表示資料全集、獨立真實性、模型效能或前瞻資格；不改舊封存、沒有自動調整模型，維持 HOLD/DISABLED。實際相容性結果以 GitHub Actions 為準。
