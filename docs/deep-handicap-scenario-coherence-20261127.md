# DHE 第十五階段：同源模型一致性與極端情境檢查

新增三個固定 pace 情境的同源診斷，不組合、不投票、不將相關模型當獨立證據。計算相對 baseline 的完整比分分布 total variation、全贏與勝波差距以及敏感度範圍，並以獨立整數四分之一盤 oracle 核對實際共同投影的讓球、大小球、聯合結算矩陣。檢查總機率、讓球與大小球門檻單調性、穿盤機率不超過勝波、pace 方向及非法分布；有錯整批拒絕。情境區間不是信賴區間，不能量化實際過度自信或模型優勢。

五個主隊率 × 五個客隊率 × 兩個方向 × 三個 pace = 150組合成情境；每情境15條深盤與41條大小球門檻 = 8400個門檻單調檢查（非獨立樣本、非真實比賽）。四組測試方法，固定率域0.1至5.5，不涉及外部資料、下注、模型調參或歷史預測重算。HOLD/DISABLED維持，尚待最新CI。
