# 第十四階段：批次復盤衝突隔離

單場橋接檢查未涵蓋跨賽事重用資料。新增批次 sidecar，最多1000筆；候選摘要、賽事ID、同聯賽主客組合及記錄開波、市場事件ID、來源投影及報價摘要、來源原生事件ID與結果摘要任一跨筆重複，所有涉及記錄均拒絕，包括結構不合格的衝突筆。不同資料類型不能藉分組繞過衝突。只輸出私有評估列及拒絕計數，不輸出原始報價。保守規則可能錯拒真正有效或同一來源批量摘要的紀錄；不能證明不同摘要為獨立來源，不能防止偽造全新ID或摘要。資料類型仍為呼叫者聲稱，不提升真實資格。

新增四組合成測試，包含256批次組合錯誤（不是256場實戰或獨立模型測試），並擴展固定 #711 跨分支合成評估，檢查兩個重複樣本隔離及兩個不同樣本通過。無網絡、正式模型或封存改動、無新增真實資料及認證，HOLD/DISABLED。最新CI尚待驗收。
