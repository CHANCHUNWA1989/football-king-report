# Live Auto research audit (not deployed)
Run on an operator-controlled machine with an authorized upstream collector:
`python ops/vnext_live_auto_audit.py /path/to/normalized-batch.json`.
Input is {"cases":[{"envelope":...,"snapshot":...,"expected_digest":...}]}, using existing evidence cut schemas. The digest must be obtained from a separately retained commitment; this tool cannot authenticate it. Use atomic replacement for the input file. The CLI reads at most 2 MB and audits at most 100 cases against its wall clock. Duplicate fixture groups are rejected; stdout is aggregate JSON only. Exit 0 means at least one structurally consistent case, NOT authenticated data or a prediction. Exit 2 means no consistent case or bad input. No provider calls, scheduling, notification or VPS provisioning are included. An external scheduler can invoke this command only after authorized collector configuration and resource review. No raw prices, xG or fixture identifiers are emitted. HOLD/DISABLED throughout.
