# DHE 前瞻配對評估器（2026-11-27）

獨立研究工單，不依賴尚未合併的 PR #710 程式，只重用現有亞洲盤 grade。目標係為未來 DHE challenger 提供同場、同線、同資訊截止時間的五類結算機率評分。

輸入須提供固定聯賽、賽事、主客 ID、開波時間、讓球方、深盤線、兩模型各自的相同身份／截止時間、封存參照、記錄時間、五類概率，以及至少兩個不同 provider ID 的 90 分鐘比分聲稱。時間須帶時區；模型記錄最遲開波前10分鐘；比分擷取至少開波105分鐘後且不晚於評估時間。重複賽事全數剔除（保守選擇：每個賽事只容許一條線，不為多重比較挑選）。拒絕不可能的結算類型、錯隊、錯線、重複供應商及衝突比分。

輸出合成與未認證外部資料分開、同場多類 Brier（五項平方誤差總和）、log loss（概率下限 1e-15）、全贏平均預測與觀察比例、按聯賽及精確讓球分層、challenger 減 baseline 的配對差。負差表示該批資料損失較低，並非證明預測提升。無樣本不回傳零損失。

**不是實際前瞻封存或來源驗證**：輸入參照及時間均為聲稱，未接入獨立原件核證、不可變存檔或市場授權。兩個 provider ID 不證明真正獨立。真實前瞻合格樣本數固定為0，沒有信賴區間、EV、收益、真實投注或正式推薦。所有輸出 HOLD / DISABLED。後續須接駁獨立證據資格閘門、按時間前瞻採集、以賽事為單位配對不確定性檢驗及分層校準。

測試為完全合成，不修改 A/B/C、原始封存、公開網站或 API 用量。

## 第三階段：配對不確定性與全贏校準診斷

新增同一模型版本配對檢查、UTC ISO 星期群組重抽樣、固定種子 20261127、2000 次 paired cluster bootstrap。每次抽樣整個星期群組，保留同週賽事相關性，按抽中賽事總數計算 challenger 減 baseline 的 Brier / Log Loss 差，輸出名義95%百分位區間。少於300場或12週、模型版本混合、超過520週不產生區間。星期間依賴及選樣偏差未獲驗證；不聲稱有效推論、顯著提升或真實前瞻信賴區間。合成及未認證外部分開，固定十個全贏機率校準桶；空桶輸出 null，不冒充零誤差。頂層 confidence_interval_available 仍為 false，因沒有真實認證前瞻樣本。所有輸出保持 HOLD / DISABLED。新增合成300場12週重現性、空樣本與版本混合測試，不代表實際賽事數量。
