# P1｜Poisson 0–11 球截斷偏差研究（2026-11-20 HKT）

## 可重現問題

主分支 `ops/shadow_forecast.py:185-195` 以每隊 `range(12)` 建立獨立泊松入球分佈，然後將 12×12 入球矩陣的已保留概率重新歸一化。兩隊預期入球上限 `5.5`，高入球時遺失的聯合尾部不一定可忽略，故可能造成 1X2 機率數值偏移。注意：這是**數值誤差**，不是模型對真實賽果欠校準的同義詞。

## 封存基線與研究層分離

- 基線：`poisson_1x2()` 保持原樣，不重算或覆寫任何已封存 A/B/C 前瞻預測。
- 新增：`ops/poisson_tail_audit.py`，只比較舊 0–11 球與每隊 0–63 球的高精度數值參考矩陣。參考矩陣尾部剩餘需低於 `1e-12`。
- 觸發：最大單項 1X2 概率偏差 > 0.1 **百分點**，回傳 `HOLD` 並顯示偏差；較低偏差亦只屬 `RESEARCH_ONLY`。
- 測試：`python -m unittest ops.tests.test_poisson_tail_audit -v`，加上完整 `ops/tests` 與原 V4.1 安全 CI。

## 合成邊界測試（不是比賽數據）

`λ_home=λ_away=5.5` 時，舊矩陣約排除 2.1856% 聯合比分概率，最大單項 1X2 偏差約 0.267 百分點，和局可能高估；`5.5 / 3.0` 最大偏差約 0.267 百分點。這些由已宣告的泊松參數計出，不屬任何球隊當日 xG，也不構成改善實際命中率、EV 或 ROI 的證據。
