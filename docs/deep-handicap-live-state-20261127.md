# DHE 第六階段：即場紅牌與比分研究

新增獨立、零網絡 live state sidecar。重用 live_score_identity_guard 的賽前身份封存聲稱、來源事件ID、URL、雙來源比分／狀態一致性，額外要求每來源紅牌數及整數正規時間分鐘完全一致、擷取及上游更新均在120秒內、正規時間階段合理。缺失紅牌不可假設為0，90分鐘後及補時不作預測。來源一致仍不等於獨立認證，紅牌時間與事件原件未驗證。

剩餘時間模型以(90-分鐘)/90比例縮放輸入的假設全場入球率，按紅牌差距調整自身及對手攻力（每張紅牌0.60/0.75/0.90自身、對方1.10/1.15/1.25三組固定配對），領先至少兩球的一方若為指定讓球方則採0.65/0.85/1.0進攻倍率。九組情境使用共同終場比分分布及既有五類結算投影。紅牌及比分狀態在剩餘時間固定，不模擬之後事件、追分戰術或補時，不當作即時xG、已校準機率或正式預測。情境區間不是統計信賴區間。正規時間全場盤線，不推斷即場盤只計剩餘入球的規則。

新增648組合成情境測試設計、主客鏡像、紅牌方向、時間縮減、資料矛盾攔截。未取得任何真實即場資料、未對接API、未認證紅牌或模型參數。所有輸出HOLD/DISABLED。既有候選及已封存資料不修改。
