# 全球賽程覆蓋擴張：第二批（2026-11-26）

原有 worldwide_source_builder 會直接略過沒有合格歷史路徑的聯賽，即使目錄已有固定 SportsDB 聯賽 ID。今次將目錄型賽程觀察同模型訓練資格分開。每次最多抽取3個目錄型聯賽（按香港日期輪替），共用原有最多12聯賽、32請求、95秒及供應商配額保護；不增加付費額度，不取盤口。保留德國及日本 J1 優先位置，但普通研究聯賽名額可能減少。只接受明確空的 source_files 和有效不衝突的目錄 ID，不把不合法路徑轉作備援。

新增資料係單來源賽程觀察，無訓練歷史、無模型資格。原有模型輸入格式保留；空 history 不能產生模型預測。來源錯誤、無賽事及未採集須分開解讀。保留原有開賽至少1小時後、7日內等限制，不代表已取得即場或所有女子及青年足球賽程。既有 TheSportsDB 免費端點可能只返回一場。未增加新外部供應商。
