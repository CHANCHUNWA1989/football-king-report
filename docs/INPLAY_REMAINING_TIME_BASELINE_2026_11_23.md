# VNext：即場剩餘時間 Poisson 基準模型（2026-11-23，研究模式）

## 實際改動
新增 `ops/inplay_remaining_goal_baseline.py` 和13項純合成測試 `ops/tests/test_inplay_remaining_goal_baseline.py`。只建立**固定基準**，供日後同未合併 PR #433 嘅動態反勝模型做同場同時間對照；本 PR **不依賴、唔複製亦唔整合** #433/#430 嘅程式。

- 輸入：**自報**賽事固定ID、賽前研究入球率及其時間、現場比分、比賽分鐘、紅牌數與快照時間。
- 假設：90分鐘等比例剩餘時間、獨立 Poisson；入球強度敏感度固定 `0.85/1.00/1.15`，不根據11月22/23日賽果追參。
- 輸出：三組**假設情景**下嘅90分鐘勝／和／負、全場大2.5／大3.5、至少再入1球的條件機率；不包括補時、加時、換人、戰術、陣容、實際xG、紅牌影響或任何盤口。
- **任何非零紅牌都 HOLD**，因為尚未有具獨立證據同樣本外驗證嘅紅牌係數。缺少紅牌欄位亦不能當零張。
- 嚴格拒絕錯誤賽事身份、賽前計算時間倒灌、比賽狀態／時刻不合理、截圖過期或未來時間、自行加入認證欄位、非有限入球率等。
- 所有輸出保持 `production_recommendations=DISABLED`、`model_scoring_eligible=false`、`probabilities_calibrated=false`、`positive_ev_verified=false`、`certified_forward_samples=0`、`recommendation=null`，研究成功都不能升級成正式推介。

## 用上次河床半場1:1解釋（**非真實賽事還原**）
測試例假設賽前入球率主1.5、客1.1，半場1:1後剩餘45分鐘，則固定1.0情景的剩餘主客入球均值為0.75／0.55，合共1.30，再入至少一球之數學概率約72.75%。**1.5/1.1係人工示例，唔係河床該場賽前封存模型概率，唔可以計作已預測命中或EV。**

```bash
python -m compileall -q ops
python -m unittest discover -s ops/tests -q
```
