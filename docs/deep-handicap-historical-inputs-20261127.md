# DHE 第八階段：歷史射門與休息時間輸入

來源：StatsBomb Open Data（https://github.com/hudl/open-data）。只接受依法取得的私有歷史事件文件；不將原始資料、真實球員數值或第三方事件分發至公開儲存庫。發布研究前須審查官方使用協議及履行來源／標誌要求。此程式不包含來源實際數據，也不新增外部下載排程。

以聲稱原生賽事與球隊 ID、事件檔路徑、SHA256、記錄賽事結束及擷取時間作結構性綁定。核對 JSON 重複鍵、非有限值、重複事件、事件 index 連續、兩個正規半場結束標記、射門身份及有效 shot.statsbomb_xg。額外時間與互射十二碼排除。輸出私人球隊與射門球員 shot xG、shots、球隊 xGA（對手 xG），不推斷非射門球員能力、上陣分鐘、助攻或下一場入球率。SHA256 與完整性標記不證明來源真實或事件全集，不證明歷史快照於過去預測前已存在。另提供兩個聲稱時間的休息小時數，不等於完整賽程或疲勞效果。

現有 GitHub research_extensions_latest.json 2026-11-26 僅目錄80項、24個賽事，observed_fixtures=0；本輪實際讀到官方世界盃2022歷史目錄64場，但事件檔讀取受限制，未取得真實xG、未執行真實資料驗收。全部測試為合成。沒有新API消耗、沒有模型權重改動、沒有正式部署或認證前瞻資料。所有輸出維持 HOLD / DISABLED。下一階段必須使用授權私有原件、完整來源映射、賽事時點見證及獨立驗證，才可研究模型校準。
