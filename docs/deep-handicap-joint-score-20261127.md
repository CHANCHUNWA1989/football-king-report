# DHE 第五階段：統一比分矩陣

新研究模組 deep_handicap_joint_score.py 使用同一完整 FT score PMF 推導 1X2、指定讓球方五類結算、大小球雙向五類結算、BTTS、前十比分和讓球×大球聯合結算矩陣。不可把相關市場的邊際概率相乘冒充聯合概率。沿用既有 asian_net 結算，假設深盤 -1.5 至 -5、大小 0 至10 的四分之一線。原 DHE 診斷改用同一 score_distribution；私有候選仍只保存讓球五類概率，不增加任何市場資料或資格。

基準仍採既有0..24正規化Poisson，條件模型採兩個0..24半場正規化分布，半場領先兩球後固定進攻倍數0.65/0.85，卷積後每隊最多48球。此有限支撐是數學近似，不宣稱實際半場分布或戰術參數經訓練。基準與上一版本的相同分布、主客對稱、聯合矩陣行列合計、大小盤互補與四分之一結算新增合成測試。無賠率、無EV認證、無新增前瞻資料、未修改已封存預測、無正式部署；HOLD/DISABLED 不變。最新提交須重新通過 CI。
