# 足球王者：HKJC 即場讓球主客和三向概率研究（HOLD）

## 針對的缺口

研究 PR #529 的剩餘時間 Poisson 情景可計算 FT 1X2，但不能直接解讀香港賽馬會「讓球主客和」市場。HKJC 三向讓球有 **獨立的讓球和賠付事件**，不等同亞洲讓球盤的 push。例如主隊受讓 +1：主隊全場 0:1 →「讓球和」；0:2 →「客隊勝[-1]」；1:1 →「主隊勝[+1]」。不准從單一勝平負勝率猜測淨勝兩球機率。

## 本 PR 的窄幅修正

- `ops/inplay_hkjc_threeway_research.py` 在 PR #529 的原有驗證後，重用其相同剩餘時間入球率與 Poisson 分布，按 **當時比分 + 完場額外入球 + 主隊整數讓球**，三向精確相加。
- 只接收整數主隊讓球 `-3..+3`，不會把 `-0.75` 亞洲讓球誤當三向市場。以 `-0.75/+0.75` 要走另一套五級結算。
- 只計三組預先固定 0.85、1.0、1.15 **未校準假設**。排除補時、加時、紅牌、即時 xG、陣容、角球及市場賠率；嚴禁拿其中一組機率當實證勝率。
- 與截圖有關的 `2.31` 只作事後記錄：無認證盤口與對應決策時刻，就不能聲稱 `2.31` 曾可實際成交、或模型當時預計的正 EV。其算術盈虧平衡概率是 `1 / 2.31 = 43.29%`，不是本模型勝率。

## 關於 2026-11-23 長野帕塞羅女足 vs 浦和紅鑽女足

本 PR **沒有**把聊天截圖轉成認證即場輸入：截圖記錄的頁面時間、真正比賽計時、博彩系統更新時刻及外部來源時鐘未完成同刻認證；亦沒有在下半場或完場後倒填賽前／即場 rates。即使完場為 0:2，都只可說截圖所示「客隊勝[-1] @ 2.31」的三向結算結果是勝出（假設賭盤接受及按此規則結算），不能當成模型曾經預測或放棄了正 EV。
