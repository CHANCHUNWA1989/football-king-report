# 深盤賽前私有候選接入 — 第四階段

零 API 調用；重用既有 market_quote_gate 私有報告與 shadow 預測原始入球率。僅限既有六聯賽。要求單一 market event、同莊家完整兩側、同市場更新時間、所有完整盤線一致、最少讓1.5球、更新距現在不逾120秒、距記錄開波超過10分鐘；模型原件最長10小時、重用 Dixon–Coles 原始輸入檢驗（只使用原始率，不使用 D 的1X2機率），拒絕賽後比分及訓練日期倒灌。精確聯賽、隊名及記錄開波相同仍不等於經認證的跨來源原生ID映射。沒有一致盤線時不挑最高價、不補盤。

候選以同一截止時間生成獨立 Poisson baseline 和固定半場領先兩球後0.85下半場攻力 challenger；0.85為預先固定研究假設，未擬合。只產生私有候選資料及SHA256，保留模型、來源投影及私有報告摘要；不輸出莊家名稱、原始賠率、結果或投注建議。摘要不是簽名、獨立見證或不可變封存，呼叫者時間仍是聲稱；不自動加入 #711 評分器的結果樣本，不新增任何認證前瞻樣本。必須另行接入可信賽前見證、原生ID映射、真實獨立雙來源90分鐘結果及現行授權流程。不得公開候選或原始報價，維持 HOLD / DISABLED。

合成測試驗證正常結構、時間、配對、盤線歧義、模型輸入與不輸出原始價格。沒有實際私有市場資料讀取、API配額變動、排程或正式部署。
