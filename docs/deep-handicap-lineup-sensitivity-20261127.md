# DHE 第七階段：正選與輪換敏感度

新增離線研究 sidecar：以同一球員 ID namespace 的預先聲稱基準十一人和稍後聲稱官方正選比較，沿用 lineup_guard 驗證正選資料結構、來源網址與預測時序。固定賽事 ID、主客與開波時間必須相同；基準名單記錄須早於正選公佈，最長七日；公佈、擷取不得晚於本次新預測，距記錄開波超過十分鐘。拒絕預計名單冒充官方聲稱、跨隊球員、重複、缺失、錯誤身份及時間。

每隊每一個變動位置使用固定敏感度三組（自身攻力0.96/1/1.02，對方入球率1.02/1/0.99），主客組合九情境。不假設每位替換都較弱。變動數量不是傷停人數、球員價值或輪換真實效果；基準名單未證明原模型已使用。所有參數均為未經擬合的假設；超出既有入球率定義域時整批不輸出。重用統一比分模型，不改既有封存預測。沒有來源獨立認證、實際正選、傷停事件、球員數據或 API 接駁，無正式推薦。HOLD / DISABLED。

五組合成測試方法包含不變陣容、正負情境、時序身份錯誤、超界全拒、主客鏡像。CI 待新提交驗證。下一步需要真實球員身份映射、官方發布原件、模型實際基準陣容綁定和樣本外校準，不可用此工具替代。
