## English request to potential live data provider (send only after procurement owner reviews)

**Subject:** Football data API licensing enquiry — live match events, model research and HK rights

Hello Licensing / Partnerships Team,

We are evaluating a football-data API for a Hong Kong–targeted analytics research system. Before making any API calls or using vendor data in a model, we would like written clarification and an appropriate license.

Please confirm which of the following use cases are permitted under the relevant paid plan and contract (separately, not implied by general app-building rights):

1. Internal historical research, real-time match analytics and model inference / model training.
2. Use of live scores, event/VAR/red cards, xG, lineups, and native match IDs, including corrections and publish timestamps.
3. Retaining exact API response bytes and request/receipt metadata in a **private access-controlled archive**, with SHA-256 evidence, reproducibility checks, and optional third-party timestamping for audit.
4. Displaying derived match probabilities, publishing analysis, and — if separately permitted — betting-oriented insight to users. We will not assume betting, redistribution or API-data resale permission.
5. Geographic coverage including Hong Kong, retention and deletion periods, allowable redistribution, license holder identity, revocation and renewal requirements.

Could you also provide the documented endpoints, rate limits, history/live coverage, source-provenance information, incident corrections, pricing, trial scope, whether any upstream feeds are shared with other providers, and the authorized contracting contact?

We will keep all live data collection and production recommendations disabled until written permission, independent compliance review and source-integrity checks are completed.

Thank you.

Football-King research project
