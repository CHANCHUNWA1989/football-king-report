# Unified live intelligence v1 — research only

This integrates the existing score-matrix and Asian settlement modules into a live research scenario. All outputs remain HOLD / DISABLED. Input identifiers and source declarations are not cryptographic proof of independence or authenticity. As-of is a replay parameter, not proof of a trusted clock. Recent non-penalty xG must come from matching windows after the last material event; no missing value is invented. A frozen pre-match prior is shared by baseline and challenger. Score-state, red-card and shrinkage multipliers are unfitted scenario assumptions; the scenario range is not a confidence interval. Lineup identity agreement is required but no player impact model is trained. Regulation 90-minute clock only; stoppage time, half-time, extra time and VAR corrections require a separate model. Asian quote must explicitly refer to the whole match and use home-signed handicap; EV is hypothetical and not executable. No external feed, bookmaker connection, OOS data, calibrated coefficients, model uplift claim, or deployment. Paired descriptive metrics do not certify OOS or cohort provenance. Audit change only compares identical priors and score/card/lineup state.

Run: python -m unittest ops.tests.test_research_unified_live_v1 -v
Synthetic examples are not actual Macarthur or Melbourne data. The 144-case score/card grid is structural testing only. Require exact-head CI, independent review, external provenance, prospective OOS calibration and trusted quote verification before any production integration.
