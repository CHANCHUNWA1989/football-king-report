# V27 same-kickoff batch and UTC clock safety
V26 required explicit availability and prevented overlapping-result leakage, but rejected all equal kickoff times. V27 accepts equal UTC kickoffs only with distinct explicit fixed fixture IDs, rejects duplicate IDs across the input and simultaneous team collisions, sorts equal-kickoff records by ID rather than score, and moves a warmup boundary to the end of a kickoff group instead of arbitrarily selecting some matches from it. If no test group remains, reject. Result availability queue and comparisons use UTC instants, including DST folds. Existing sequential synthetic fixtures without IDs remain compatible; supplied IDs and availability are not independently authenticated. Seven regression methods test permutation, duplicate and missing IDs, team collisions, warmup, offsets and DST. No new model weights, original ledger modification, deployment or performance claim.
