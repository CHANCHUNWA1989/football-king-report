# Private cohort directory extension to V10
V10's single JSON input is bounded at 2 MB; a sufficiently large valid cohort can exceed this limit before V8's minimum training/test sample gates. This optional loader keeps each case <=2 MB, total <=64 MiB, <=1000 files; it does not promise every 200-case cohort fits. Linux directory FD, no symlinks or hardlinked members, strict roster and SHA-256 of exact case bytes. Manifest.json contains schema private-live-cohort-manifest-v1, model_release, train_start, train_cutoff, test_end, members (unique SHA-256 hex strings). Each <sha>.json is a V10 case with raw_captures as hex strings. Run python -m ops.research_live_cohort_directory --directory PRIVATE_DIR. Keep the directory private, outside the public repository; no network or storage provisioned. Manifest is local, not immutable or independently timestamped; roster verification only checks supplied files. V10 reviews every case before scoring. No authenticated admission, production activation or new feed. Unit test uses 200 synthetic padding files to test loader capacity, not actual forecasts. Run python -m unittest ops.tests.test_research_live_cohort_directory -v. Existing V10 interface stays unchanged.
