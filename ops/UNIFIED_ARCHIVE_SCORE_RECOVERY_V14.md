# V14 fixed-ID archive recovery
Read existing OpenLigaDB gzip snapshots for ledger rows with a previously recorded OpenLigaDB match ID, Bundesliga scope, exact kickoff and team identity. Scan UTC kickoff date and following three dates, bounded to 1500 compressed files, 1MB compressed / 2MB decoded each. Candidate score conflicts and mismatches are held; repeated snapshots never become two independent sources. Existing ledger and sealed forecasts remain unchanged. A source-reported final is not proof of regulation-time score, publisher independence, or independent forecast timestamp. Inspection of main on 2026-11-27 found 18 fixed IDs among 128 rows; latest 28-row Germany snapshot had zero target ID matches. Gzip archive bytes could not be decoded through the connector; the added test runs actual checked-out archived files in CI and prints aggregate counts. Run python -m ops.research_archive_score_recovery_v14 and python -m unittest ops.tests.test_research_archive_score_recovery_v14 -v. No API call or model training; HOLD/DISABLED.
