# V10 unified offline live research pipeline
One entry point binds V4/V5 intake to V2 forecast and V3 settlement/evaluation, then V8 calibration. Replays receipt against exact original envelope bytes and original policy before scoring. Mixed model releases, duplicate fixtures, changed bytes or policy, and contradictory final scores fail the whole submitted cohort. Local hashes are not independent witnesses. No source authentication, real feed collection, market executability, complete cohort evidence or production activation. V6/V7 legacy diagnostics and V9 availability audit remain separate to avoid merging legacy and live evidence. Use python -m unittest ops.tests.test_research_live_pipeline_v10 -v. Optional offline CLI: python -m ops.research_live_pipeline_v10 --input PRIVATE_LOCAL_COHORT.json; object keys model_release, train_start, train_cutoff, test_end, cases; case keys receipt, raw_captures (hex encoded exact bytes), policy, final_observations, settled_at. CLI uses current UTC, max input 2 MB, no raw data output, no publication; keep licensed input private. Synthetic test coverage only, no independently authenticated samples or claimed prediction uplift. No changes to deployed workflows.
