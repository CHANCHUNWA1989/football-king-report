# V23 bounded forward operations (HOLD/DISABLED)

`python -m ops.v23_forward_cycle --db /private/ledger.sqlite` checks outstanding BL1 fixtures two hours after kickoff, requests at most two public OpenLigaDB season payloads per invocation, validates exact payload hashes, clocks, league scope, and settles at most 100 pending fixtures. No due fixture means zero calls. Failures remain pending, with reason counts; no automatic retries or second-provider calls. Oldest season/fixture first; a large permanently unresolved backlog can defer newer rows and requires manual review. Repeated invocations skip already-settled fixtures. This is single-source research, not source-independent verification. It does not generate new forecasts.

Optionally supply `--archive sealed.zip --archive-sha256 EXPECTED_SHA256 --archive-created-utc ISO_TIMESTAMP` to import a genuine existing V6.2 forecast archive before the cycle. `--backup /private/backup-new.sqlite` creates an exclusive consistent SQLite snapshot with integrity check, foreign-key check, report re-audit and SHA256. Keep backups private and verify their digest against an independently stored copy before restoring. Owner-controlled persistent storage and backup retention required. CI reopens temporary runner DB and checks backup, but publishes only reports and the V22 forecast ZIP with 14-day retention; no raw result database is published.

For an authorized persistent Linux host, an example manual scheduling design is an hourly cron invocation of the command above using a host-level flock and a private persistent volume, with bounded log retention. Review provider terms/rate budget, lock, environment and permissions before enabling. No cron, VPS, GitHub default-branch schedule, persistent external storage, credential, or monitoring service is activated by this PR. A separate forecast producer must supply pre-kickoff archives. Real second-source data, independent identity/clock attestation and external witnesses remain required. Zero verified forward credit and no production recommendations.
